# Auto

Локальный Python-проект для автоматизации действий через `pyautogui` с настраиваемым сценарием и графическим интерфейсом.

## Что внутри

- `clicer.py` - движок исполнения сценария из `config.json`.
- `gui.py` - основной графический интерфейс.
- `gui.pyw` - запуск GUI без консольного окна.
- `config.json` - конфиг проекта и список действий сценария.
- `requirements.txt` - зависимости проекта.
- `setup.ps1` - создание `.venv` и установка зависимостей.
- `run.ps1` - запуск сценария из консоли.
- `run-gui.ps1` - запуск GUI через `pythonw`.
- `run-gui.vbs` - тихий запуск GUI без видимой консоли.
- `register-task.ps1` - регистрация задачи в Планировщике Windows.

## Быстрый старт

```powershell
.\setup.ps1
.\run-gui.ps1
```

Если нужен полностью тихий запуск без окна PowerShell, используйте `run-gui.vbs`.

## Что умеет интерфейс

- редактировать общие настройки запуска;
- управлять сценарием как списком действий;
- добавлять, дублировать, удалять и переставлять шаги;
- менять параметры выбранного действия в правой панели;
- записывать действия мыши и клавиатуры;
- запускать сценарий без отдельной консоли;
- показывать лог прямо в окне;
- открывать папку логов одной кнопкой.

## Запись действий

1. Нажмите `Запись действий`.
2. Выполните нужные действия мышью и клавиатурой.
3. Нажмите `F8`, чтобы остановить запись.
4. Записанные шаги добавятся в конец сценария.

## Конфиг

`config.json` хранит:

- общие параметры запуска;
- логирование;
- список `actions`, из которого собирается сценарий.

Благодаря этому теперь можно настраивать не только интервалы, но и саму последовательность действий.

## Консольный запуск

```powershell
.\run.ps1 -NoPrompt
```

## Планировщик Windows

```powershell
.\register-task.ps1 -TaskName AutoClicer -At 09:00
```

## Сборка Windows

Чтобы собрать автономную Windows-версию без зависимости от установленного Python:

```powershell
.\build-installer.ps1
```

После сборки появятся файлы:

- `dist\EmulationWork.exe` - переносимый `exe`;
- `dist\installer\EmulationWorkSetup.exe` - установщик Windows.

Установленная версия хранит пользовательские данные отдельно от папки программы:

- конфиг: `%LOCALAPPDATA%\EmulationWork\config.json`
- логи: `%LOCALAPPDATA%\EmulationWork\logs\`

Установщик ставит приложение в профиль текущего пользователя, поэтому администраторские права не требуются.
